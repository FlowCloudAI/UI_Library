# flowcloudai-ui 0.2.3 变更说明

## 概览

`0.2.3` 是一次以“性能与交互稳定性提升、编辑能力增强、语义令牌体验完善”为核心的版本升级。  
本次改动覆盖 `Tree` 系列、`VirtualList`、输入与滑块控件、`RollingBox`、`Alert`、`RelationGraph`、`TeraEditor`、`MarkdownEditor` 等核心组件，并补充了对应演示与文档。

## 主要变更

### 1) Tree 与 VirtualList：可见行语义更清晰，性能边界更稳

- `Tree` 与 `VirtualList` 联动增强，支持真实视口范围回调。
- `VirtualList` 新增 `VirtualListVisibleRange` 与 `onVisibleRangeChange`：
  - 回调返回 `{ startIndex, endIndexExclusive }`，该范围为“真实视口范围”，不含 overscan。
- `Tree` 新增对外类型与回调：
  - `TreeVisibleRow`
  - `TreeViewportRowsPayload`
  - `onVisibleRowsChange`（树当前实际可见行）
  - `onViewportRowsChange`（当前真实视口行）
- `scrollHeight` 语义调整：
  - 不再硬编码固定高度行为，未传时会尝试填充父容器高度，适配更灵活的布局场景。
- `Tree` 默认行高契约固定，配合 `virtualRowHeight` 对齐虚拟列表计算，减少高度抖动。
- 右键菜单新增“展开/收起”动作，原“全部展开/收起”改为“递归展开/收起”语义更清晰。
- 编辑提交增加防重入保护（避免 `Enter` 与 `blur` 重复提交）。

### 2) 输入、滚动、按钮与选择类组件修正

- `Input`
  - 新增推荐回调 `onValueChange`。
  - 保留 `onChange` 兼容。
  - 数字输入新增内置 stepper（加减）控制（可关闭）。
  - 清空行为同步触发新回调。
- `Slider`
  - 增加 `min/max/step/value/defaultValue` 的安全归一化，非法参数自动回退。
  - `range=true` 下的输入类型兼容性增强。
  - 拖拽计算对零尺寸轨道进行防护。
- `RollingBox`
  - 新增 `axis`：`x | y | both | none`。
  - `horizontal/vertical` 保留兼容，`axis` 优先级更高。
- `Button`
  - 新增默认 `type="button"`，避免无意提交表单。
- `Select`
  - 分组渲染时修复组内索引基准累计逻辑，避免高亮与键盘导航偏移。

### 3) 主题与弹窗交互能力增强

- `ThemeProvider`
  - 新增 `useOptionalTheme()`，使某些组件在未包裹主题上下文时也能有安全回退行为。
- `MarkdownEditor`
  - 使用可选主题读取，不再强依赖上下文存在。
- `AlertProvider`
  - 改为队列化串行展示，避免并发弹窗覆盖。
  - 增加 `id` 标识与 Promise 生命周期治理，组件卸载时正确清理未完成请求。

### 4) 结构图与关系图能力增强

- `RelationGraph`
  - 支持显式 `two_way` 时双向箭头。
- `BidirectionalEdge`
  - 新增成对边配对偏移控制，降低反向双边重叠。
- `RelationGraph/types.ts`
  - 新增 `LayoutProvider` 接口类型，便于宿主侧组织多套布局策略。
- `ConversationTreeView`
  - 防御性修复自引用父节点及父链循环，防止构建异常树导致死循环。
- `Timeline`
  - 年份区间归一化与退化边界修复。
  - 横向滚动改为 `RollingBox axis="x"`。

### 5) TeraEditor 专项升级

- `TeraEditor` 新增外部可控样式参数：
  - `fontFamily`
  - `fontSize`
  - `lineHeight`
- Monaco 编辑器默认滚动与浮层行为优化：
  - `smoothScrolling`
  - `fixedOverflowWidgets`
- 编辑状态样式改为组件级语义 token 控制（占位、状态栏、hover/分隔/代码块等）。
- 语法高亮与主题颜色与设计 token 更贴近库内语义体系。
- 新增 demo 场景中字体与行高调节示例。

### 6) 演示与文档

- `app` 新增 `SemanticTokensDemo`，完整展示主色、背景、文本、边框、状态、语义色彩 token 的实际效果与组织方式。
- `docs/TeraEditor.md` 增补排版定制说明。
- 新增 `docs/0.2.4.md`（本文）。

### 7) 依赖与运行脚本

- `ui/package.json` 升级版本至 `0.2.3`（本版本说明中已含本次迭代）
- 关键依赖同步为稳定版本：
  - `@monaco-editor/react` -> `^4.7.0`
  - `monaco-editor` -> `^0.55.1`
- `ui/package.json` 新增 `overrides`，约束 `monaco-editor` 的 `dompurify`。
- 新增 `ui/npm-shrinkwrap.json`（锁文件补齐）。
- 新增本地构建/联调脚本：
  - `build.bat`
  - `build and run.bat`

## 兼容性提示

- 推荐迁移：`Input` 使用 `onValueChange` 替代 `onChange`（兼容但会有提示）。
- 推荐迁移：`RollingBox` 使用 `axis` 替代 `horizontal/vertical`。
- `Button` 默认类型变更为 `button`，表单内按钮如需提交请显式声明 `type="submit"`。
- `Tree` 若依赖固定 400px 内部高度，请显式传 `scrollHeight`；未传时将走父容器填充模式。
- `Tree` 虚拟滚动使用固定行高模型，若自定义行高样式，请同步 `virtualRowHeight`。
