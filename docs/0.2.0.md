# flowcloudai-ui 0.2.0 变更说明

## 概览

`0.2.0` 这一版不是零散修补，包含一批新的对外能力、组件行为增强和若干兼容性修正，已经达到一次次版本发布的范围。

这一轮变化主要集中在以下几个方向：

- `Tree` / `VirtualList` 的性能与可观测性增强
- 编辑器相关组件（`TeraEditor`、`MarkdownEditor`）的可用性提升
- 基础表单与容器组件（`Input`、`Slider`、`RollingBox`、`Button`）的 API 和容错增强
- 交互组件（`Alert`、`ContextMenu`、`SideBar`、`Select`）的稳定性与可访问性修正
- 结构类组件（`ConversationTreeView`、`Timeline`）的边界行为修正
- Monaco 相关依赖升级

## Tree / VirtualList

### Tree 性能优化

- `Tree` 改为基于“当前可见行”渲染，折叠分支不再继续挂载整棵子树。
- `Tree` 默认走虚拟列表渲染路径，大树场景下初始渲染、搜索、展开和拖拽开销明显下降。
- 未启用 `onMove` 时，`Tree` 会跳过拖拽相关逻辑，避免无意义的 `dnd-kit` 成本。
- `actionDisplayMode="auto"` 的宽度测量从节点级收敛到容器级，减少了大量 `ResizeObserver`。
- 树内搜索改为基于预处理索引执行，并配合延迟值减少输入时的同步计算压力。

### Tree 新增对外类型与回调

- 新增 `TreeVisibleRow`：

```ts
export interface TreeVisibleRow {
  key: string
  node: CategoryTreeNode
  level: number
  isExpanded: boolean
}
```

- 新增 `TreeViewportRowsPayload`：

```ts
export interface TreeViewportRowsPayload {
  startIndex: number
  endIndexExclusive: number
  rows: TreeVisibleRow[]
}
```

- `TreeProps` 新增：
  - `onVisibleRowsChange?: (rows: TreeVisibleRow[]) => void`
  - `onViewportRowsChange?: (payload: TreeViewportRowsPayload) => void`
  - `virtualRowHeight?: number`
  - `virtualOverscan?: number`

### Tree 高度模型调整

- `Tree` 默认不再使用固定的内部滚动高度。
- 未传 `scrollHeight` 时，`Tree` 会尝试填充父容器剩余空间，并在内部自动扣除搜索栏、底部操作区等占位。
- `scrollHeight` 现在更明确地表示“列表视口显式高度覆盖”，适合 demo、弹窗、固定尺寸面板等特殊场景。
- 这意味着宿主不需要再手工推算 `Tree` 内部 header / footer 占掉的高度。

### Tree 固定行高合同

- `Tree` 的虚拟滚动使用固定行高模型，默认行高为 `34px`。
- `virtualRowHeight` 会同步驱动 `VirtualList.itemHeight` 和 Tree 内部 CSS 变量 `--fc-tree-row-height`。
- 行内容会被约束在固定行高内布局，避免自定义标题或操作区把真实 DOM 高度撑大后导致虚拟列表总高度失真。
- 如果调用方修改行高相关 CSS，需要同步传入匹配的 `virtualRowHeight`。

### Tree 回调语义

- `onVisibleRowsChange` 返回的是“当前树里实际显示出来的行”：
  - 已应用搜索过滤
  - 已应用展开/折叠
  - 不包含选中态，避免因 `selectedKey` 变化产生噪音触发
- `onViewportRowsChange` 返回的是“当前真实视口中的行”：
  - 使用 `startIndex` + `endIndexExclusive`
  - 不包含 overscan 区间
  - 适合按屏幕内真实可见节点做预取

### Tree 交互增强

- 内部默认右键菜单新增单层 `展开 / 收起`。
- 原来的 `全部展开 / 全部收起` 调整为 `递归展开 / 递归收起`，语义更明确。
- 编辑态提交增加幂等保护，避免 `Enter` 与 `blur` 重复提交。

### VirtualList 新增范围回调

- `VirtualList` 新增 `onVisibleRangeChange?: (range) => void`。
- 回调语义固定为“真实视口范围”，不是带 overscan 的渲染范围。
- 新增导出类型：

```ts
export interface VirtualListVisibleRange {
  startIndex: number
  endIndexExclusive: number
}
```

## 编辑器与主题

### ThemeProvider / MarkdownEditor

- `ThemeProvider` 新增 `useOptionalTheme()`。
- `MarkdownEditor` 改为优先使用 `useOptionalTheme()`，在没有包裹 `ThemeProvider` 时会回退到亮色主题，不再强依赖外层主题上下文。

### TeraEditor

- `TeraEditorProps` 新增：
  - `fontFamily?: string`
  - `fontSize?: number`
  - `lineHeight?: number`
- Monaco 编辑器配置同步支持上述排版项。
- 新增 `smoothScrolling` 和 `fixedOverflowWidgets`，改善滚动与浮层体验。
- 占位文本、状态栏、hover、代码块、分隔线等样式改为由组件级 CSS 变量控制，宿主更容易覆盖。
- Monaco light / dark theme 重新对齐库内设计令牌，补齐了：
  - 光标
  - 当前行高亮
  - 括号匹配
  - Hover Widget
  - 状态栏
  - 错误 / 警告 / 信息色
- Tera 语言主题与高亮规则整体强化，更贴近库的设计系统。

## 基础组件

### Input

- 新增 `onValueChange?: (value: string) => void`，作为推荐的值变更回调。
- 旧的 `onChange(value)` 继续保留兼容，但会在开发环境给出弃用提示。
- 清空操作现在会同时触发 `onValueChange('')`。

### Slider

- 增加 `min / max / step / value / defaultValue` 的归一化处理。
- 非法配置会在开发环境打印提示，而不是直接进入异常状态。
- `range=true` 但传入单值时会做安全归一化。
- 拖拽时新增轨道尺寸保护，避免宽高为 `0` 时出现错误计算。

### RollingBox

- 新增 `axis?: 'x' | 'y' | 'both' | 'none'`。
- `axis` 的优先级高于旧的 `horizontal / vertical`。
- 旧的 `horizontal / vertical` 继续兼容，但在开发环境会提示迁移到 `axis`。
- 新增 `.fc-roll--both` 和 `.fc-roll--none` 样式分支。
- 水平滚轮映射逻辑改为基于 `axis === 'x'`。

### Button

- `Button` 默认补上 `type="button"`。
- 这样在表单中使用时，不会因为未显式指定类型而意外触发表单提交。

## 交互与容器

### Alert

- `AlertProvider` 从“单次覆盖式弹窗”改为“带队列的串行处理”。
- 新增内部 `id` 标识，保证异步回调与当前激活弹窗一一对应。
- Provider 卸载时会正确 reject 当前与排队中的请求，避免悬空 Promise。
- 自动关闭逻辑改为基于当前激活项校验，避免旧定时器串扰。

### ContextMenu

- 新增 `ContextMenuTriggerEvent` 类型，允许组件传入更轻量的触发事件形状。
- `showContextMenu` 的参数类型从原生 `MouseEvent` 放宽到 `ContextMenuTriggerEvent`。
- 增加浏览器环境保护，避免在非浏览器环境访问 `window`。
- 菜单定位逻辑在不可见态下不再做多余视口计算。

### SideBar

- 禁用状态的链接项不再继续挂真实 `href`。
- 补充了 `aria-disabled` 和 `tabIndex` 处理。
- 点击禁用项时会阻止默认行为和事件冒泡。

### Select

- 分组渲染时修正了组选项的基准索引计算。
- 现在每组的 option index 会连续累加，避免高亮、键盘导航或虚拟化索引错位。

## 图形与结构类组件

### ConversationTreeView

- 构树时增加自指父节点保护，避免 `parent === id` 的坏数据直接形成异常结构。
- 回溯根路径时加入 visited 集，避免循环父链导致死循环。

### Timeline（Time）

- 新增年份范围归一化，自动处理 `yearStart > yearEnd` 或非有限值。
- 当区间退化到单年时，仍然会稳定生成一个 tick。
- 横向滚动改为使用 `RollingBox axis="x"`。

## 依赖与打包

- `flowcloudai-ui` 版本号提升为 `0.2.0`。
- `@monaco-editor/react` 从 RC 版升级到稳定版 `^4.7.0`。
- `monaco-editor` 升级到 `^0.55.1`。
- `ui/package.json` 新增 `overrides`，将 `monaco-editor` 内部 `dompurify` 约束到 `^3.4.2`。

## 兼容性提示

- `Input.onChange(value)` 仍可用，但建议迁移到 `onValueChange(value)`。
- `RollingBox.horizontal / vertical` 仍可用，但建议迁移到 `axis`。
- `Tree.onVisibleRowsChange` 不包含 `isSelected`；如果业务需要选中态，需自行结合 `selectedKey`。
- `VirtualList.onVisibleRangeChange` 返回的是真实视口范围，不含 overscan。
- `Tree` 未传 `scrollHeight` 时会改为填充父容器，因此宿主需要给外层容器提供可收缩的高度上下文（常见做法是 `display: flex` 且链路上包含 `min-height: 0`）。
- `Tree` 虚拟滚动要求固定行高；修改行高样式时需要同步调整 `virtualRowHeight`。
- `Button` 默认 `type="button"` 可能改变表单内未显式配置按钮的提交行为，但这是期望修正。

## 建议的调用方关注点

- 依赖 `Tree` 大数据量场景的调用方，可以直接接入 `onVisibleRowsChange` 或 `onViewportRowsChange` 做预取。
- 依赖 `MarkdownEditor` 的调用方，如果之前为了避免主题报错额外包了一层空 `ThemeProvider`，现在可以简化。
- 依赖 `TeraEditor` 的调用方，可以把字体与行高配置外提到宿主主题层。
- 依赖 `RollingBox` 的调用方，后续新代码建议统一使用 `axis`。
